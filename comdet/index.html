Community-Detection Algorithms

A gallery of CD algorithms walked stage by stage on a shared 32-node fixture. Companion to the netgen gallery of synthetic-network generators.

Under construction. Pages ship with placeholder walkers; faithful JS kernel ports of leidenalg, infomap, graph-tool SBM, constrained-clustering, and VieCut land per Phase 4c of the active plan.

Base algorithms

Leiden (CPM)

leidenalg + libleidenalg

Move-refine-aggregate optimizer minimizing the constant Potts model objective. Resolution slider exposes the multi-scale partition.

Leiden (Modularity)

leidenalg + libleidenalg

Same algorithm, modularity objective. Walker shows the refinement phase that distinguishes Leiden from Louvain.

Infomap

infomap

Map-equation flow. Pre-MCMC PageRank flow, then greedy joining + tuning + sublevel optimization until L(M) stops shrinking.

IKC

networkit core decomposition

Iterative k-core peeling. Walker exposes the layered cores + the modularity-gating that drops sub-modular peelings.

SBM flat (deg-corr)

graph-tool

Multilevel MCMC sweep over flat block partitions, with degree correction. Walker steps through merge_sweep + mh_sweep.

SBM flat (no deg-corr)

graph-tool

Same multilevel MCMC, no degree correction. Comparison page surfaces where ndc and dc disagree on hub assignment.

SBM flat (planted partition)

graph-tool

Planted-partition prior favoring equal-size blocks.

SBM nested (deg-corr)

graph-tool

Hierarchical SBM as a Python composition over per-level flat BlockState instances.

SBM nested (no deg-corr)

graph-tool

Hierarchical, no degree correction.

SBM flat (best)

graph-tool meta

Picks the lowest-entropy variant from {flat-dc, flat-ndc, flat-pp}.

SBM nested (best)

graph-tool meta

Picks the lowest-entropy variant from {nested-dc, nested-ndc}.

Post-processors

CC (connected components)

igraph weakly_connected_components

Splits any cluster that is internally disconnected. The 32-node fixture's cluster C (two 3-cycles, no inter-edge) exposes this cleanly.

WCC (well-connected components)

VieCut + constrained-clustering

Cluster > mincut > if cut < threshold(criterion), split > recurse. Cluster B (two K_4's joined by 1 edge) splits at log threshold.

CM (Connectivity Modifier)

constrained-clustering CM + libleidenalg

Mincut, then re-run Leiden on each piece, repeat to fixed point. Shipped only with Leiden-CPM and Leiden-Mod base algos.
Fixture: 32 nodes, 4 planted communities, 2 outliers, 49 edges. Source-of-truth at js/fixture.js.
