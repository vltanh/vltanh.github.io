flat SBM, lowest entropy

Run flat-dc, flat-ndc, flat-pp from the same seeded init; rank by pairwise \(\Delta\Sigma\) under Peixoto's Bayes-factor reading.

Draft. Meta-page over the three flat-SBM variants. Each runs the same MCMC chain (uniform proposal, \(\beta = 1\), 20 sweeps) from the same seeded random init; each variant minimises its own description length under its own priors. \(\Sigma\) values across variants are not directly comparable in absolute terms (different priors, different likelihoods); the page surfaces the pairwise gap and the per-variant verdict (\(|\Delta\Sigma| < 5\) nats = inconclusive, 5–10 = suggestive, beyond 10 = decisive per Peixoto 2017 §VII.A's Bayes-factor reading). Bit-equality vs. the cpp tracer holds for each variant across the 17-fixture 3-tier stress panel.

The flat SBM family has three principled variants: degree-corrected, non-degree-corrected, and planted-partition. Each makes a different prior assumption about the data, and there is no a-priori reason to pick one over another on an unseen network. The standard recipe is to run all three and pick the variant with the lowest description length, treating that choice as a Bayesian model-selection step. That is what flat-best does in run_cd.sh; this page is the same recipe with the comparison surfaced.

DC degree-corrected sparse entropy; degree-DL prices the per-node degree sequence given block sums. Survives heavy-tailed degree distributions and clusters that mix hubs with leaves.
NDC non-degree-corrected sparse entropy; the vertex term scales with \(n_r\) instead of \(e_r\). Useful when degree variance carries cluster signal that DC would otherwise absorb into the model.
PP planted-partition (Zhang + Peixoto 2020). Two-rate Bernoulli with intra-block density \(p_{\text{in}}\) and inter-block \(p_{\text{out}}\). Strongest assortative prior; cleanest when blocks really are denser inside than outside.

caveat · \(\Sigma\) across variants is not directly comparable

The three variants compute \(\Sigma\) under different priors and different data-fit terms; the absolute values sit on different scales. Picking the lowest is meaningful when the variants share the same model class (Peixoto 2017 §VII.A) and should be read as "this variant compresses the data better under its own assumptions" rather than a strict ranking. The Bayes-factor odds \(\Lambda = 2^{-\Delta\Sigma}\) applies pairwise when the variants compete as alternative explanations; on the 32-node fixture the gap is usually wide enough that the verdict is stable across seeds.
