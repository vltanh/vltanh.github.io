Community detection as Bayesian inference: posit a generative model where each node carries a block label \(b_i \in \{1,\dots,B\}\), the model freezes the count of edges between every pair of blocks \(e_{rs}\), and the actual graph is a uniform draw from the simple graphs that meet those constraints. The inference problem is the inverse: given the observed graph, find the partition that compresses it the most.

The microcanonical formulation gives a clean target: the partition that minimises \(\Sigma = -\log P(\boldsymbol{A}, \boldsymbol{e}, \boldsymbol{b})\). Each candidate partition carries a cost in nats, split between data fit and model complexity. The minimum sits in the middle.

The nested SBM stacks multiple flat blockmodels into a hierarchy: level 0 is the input graph plus its block partition; level \(l\) is the block-multigraph collapsed at level \(l-1\) plus its own block partition. The hierarchical prior raises the resolution limit from the flat SBM's \(B_{\max} \propto \sqrt{N}\) to nested's \(B_{\max} \propto N / \log N\). This page runs the level-0 walker for the non-degree-corrected nested SBM, which treats every node in a block as exchangeable and lets degree heterogeneity show up in the data fit. The sister nested-dc page handles the same fixture under a degree-conditional prior.

On the 32-node fixture the resolution-limit benefit of the nested form is mostly cosmetic: \(\sqrt{32} \approx 5.7\), so the flat SBM can already represent the 4-community ground-truth comfortably. The hierarchy starts paying for itself when \(B^{\star} \gtrsim \sqrt{N}\), so this page is more of a structural reference than a place to see nested do better than flat at a given size. Without degree correction, A's hub (node 0, degree 9) tends to peel off into its own block: NDC has no way to absorb the degree gap under an exchangeable-within-block prior.

stage 1 · random init

Random partition with \(B_0\) blocks; \(\Sigma_0\) on display.

MCMC starts from any valid partition. The level-0 chain initialises with \(B_0 = \) 8 blocks: the kernel shuffles the identity permutation under MT19937 and assigns block \(i \bmod B_0\) to vertex \(\sigma(i)\). The shuffle is backward Fisher-Yates, matching std::shuffle in the cpp tracer.

\(\Sigma_0\) is large because the random partition is uninformative: edges cross block boundaries roughly uniformly, the sparse-entropy term gets no concentration discount, and the chain still pays the full edges-DL + partition-DL cost. MCMC's job is to push \(\Sigma\) down by re-routing nodes.

stage 2 · one move at a time

Each visit: pick a vertex, propose a target block, accept or reject.

One sweep visits every level-0 vertex once in shuffled order. Each visit runs four steps:

  1. Build the candidate pool: every currently non-empty block at level 0, plus one fresh empty slot when the vertex's current block holds more than one member.
  2. Sample a target uniformly from the pool (the \(c \to \infty\) limit of graph-tool's sample_block; the canonical proposal weights candidates by neighbour-block frequencies).
  3. Compute \(\Delta\Sigma\) for the move via virtualMove.
  4. Accept with \(\min(1, e^{-\beta\Delta\Sigma})\) at \(\beta = 1\). On accept, commit; on reject, leave the partition unchanged.

The kernel composes NestedBlockState over the level-0 mode partition: level \(l + 1\) is a flat NDC BlockState on the level-\(l\) block-multigraph (vertices = non-empty level-\(l\) blocks, edges = level-\(l\) \(e_{rs}\) counts). Per-level MCMC and joint multi-level inference exist in the kernel and the cpp tracer; the walker on this page shows only the level-0 trajectory.

how the hierarchy composes

Level 0's mode partition collapses into the level-1 graph: vertices are the non-empty level-0 blocks renumbered \(0\ldots B_{\text{ne}}-1\), edges carry the level-0 \(e_{rs}\) counts as weights, and self-loops carry \(e_{rr}/2\) per the doubled-diagonal convention. Level 1 is itself a flat NDC BlockState over that smaller multigraph. The nested total \(\Sigma_{\text{nested}} = \sum_l \Sigma_l\) (self-consistent across levels). The walker on this page only animates level 0; the full multi-level e_rs propagation runs end-to-end in nested_state.js and the cpp tracer matches it byte-for-byte under the 3-tier stress panel.
