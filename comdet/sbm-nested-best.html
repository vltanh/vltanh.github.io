SBM-nested-best

nested SBM, lowest entropy

Run nested-dc + nested-ndc on the same fixture from the same random init; pick the variant with the lowest description length.

Draft. Meta-page over the two nested-SBM variants (DC, NDC). Each runs the level-0 MCMC chain (uniform proposal, β=1, 20 sweeps); each variant minimises its own description length under its own priors. Σ values across variants are not directly comparable in absolute terms (different priors, different likelihoods); the page surfaces the gap and the per-variant verdict (within ±5 nats = inconclusive, ±5–10 = suggestive, beyond ±10 = decisive per Peixoto §VII.A). The Bayes-factor reading Λ = e-ΔΣ applies pairwise; cross-variant absolute Σ comparison is suggestive but not decisive on small fixtures.

The nested SBM family has two principled variants: degree-corrected and non-degree-corrected (planted-partition has no nested counterpart in graph-tool). Each makes a different prior assumption about the data. There is no a-priori reason to pick one over another on an unseen network, so the standard recipe is to run both and pick the one with the lowest description length. That's what nested-best does in run_cd.sh; this page is the same recipe with the comparison panel surfaced.

DC sparse-entropy with degree correction; degree DL prices the per-node degree sequence given block sums. Survives heavy-tailed degree distributions.
NDC sparse-entropy without degree correction; vertex term scales with \(n_r\) instead of \(e_r\). Useful when degree variance carries cluster signal that DC would absorb.

caveat · Σ across variants is not directly comparable

The two variants compute Σ under different priors and different data-fit terms; the absolute Σ values are on different scales. Picking the lowest is meaningful when the variants share the same model class (Peixoto's review §VII.A) but should be read as "this variant compresses the data better under its own assumptions" rather than a strict ranking. The canonical posterior-odds-ratio Λ = 2-ΔΣ applies when the variants compete as alternative explanations; on the 32-node fixture the gap is usually big enough that the verdict is stable across seeds.
