Synthetic Network Generators

Seven algorithms for sampling graphs that match an empirical network in targeted ways. Each page animates the default-settings algorithm step by step.

Every generator takes the same inputs at the repo boundary: an undirected edge list and a reference clustering. Stage 1 extracts a small statistical profile (degrees, cluster sizes, mixing parameters, block matrices, mincuts); stage 2 hands the profile to a parametric sampler.

The question each generator answers: given an empirical network G, what does the synthetic G' guarantee to look like? Some stats are exact matches (node count, block structure); some hold only in expectation (global ξ, degree distribution); one is pursued via a search that does not always converge (nPSO's clustering coefficient).

All seven visualizations below use the same small 20-node synthetic input, so differences in what each generator preserves become visible side by side.

sbm
Degree-corrected micro-SBM via graph-tool. Thinnest wrapper: one function call plus self-loop and parallel-edge cleanup.

ec-sbm-v1
SBM with per-cluster edge-connectivity guarantee: Kk+1 cores, SBM overlay on mutated probs, outlier-only SBM, heap-greedy degree matcher.

ec-sbm-v2
Architectural cleanup of v1: constructive cores only, residual SBM over all blocks, block-preserving 2-opt rewire, hybrid degree matcher.
ec-sbm · 13 steps
abcd
Artificial Benchmark for Community Detection. Configuration-model hybrid with per-node split by global mixing ξ. Julia sampler.
config model · 10 steps
abcd+o
ABCD with explicit outlier mega-cluster (cluster_id=1). Outliers have dint=0 and cannot pair with each other in the external config model.
config model · 12 steps
lfr
Lancichinetti-Fortunato-Radicchi benchmark. Fits power laws to degrees and cluster sizes, resamples both, then runs a config-model hybrid with mean-μ split.
config model · 12 steps
npso
Non-uniform Popularity-Similarity Optimisation. Embeds nodes in a hyperbolic disk and runs a secant-over-midpoint search on temperature to hit a target global clustering coefficient.
geometric · 11 steps
