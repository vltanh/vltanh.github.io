ABCD

Artificial Benchmark for Community Detection

Output is a union of \(k+1\) independent random graphs: one per cluster plus a background graph over all nodes. The scalar \(\xi\) sets the share of each node's weight that goes to the background.

Given a network \(G\) with a clustering, the goal is a synthetic twin that keeps both the degree sequence and the cluster sizes verbatim while drawing every edge fresh. ABCD models the graph as a union of independent random graphs, one per cluster plus one global background, with a single scalar \(\xi\) trading weight between the two.

Each node \(u\) has weight \(w_u\) (its target degree). ABCD splits this weight: \(y_u = (1 - \xi) w_u\) funds the cluster graph of \(u\)'s home cluster; \(z_u = \xi w_u\) funds the background graph on \(V\).

A configuration model on each cluster graph produces cluster-internal edges; a configuration model on all \(z\)-stubs produces background edges that can pair any two nodes. The final graph is the union. At \(\xi = 0\) the output is disjoint cluster graphs; at \(\xi = 1\) it is a pure random graph with no signal about cluster membership.

\(\xi\) is the only structural dial in the model. ABCD does not target triangle counts, clustering coefficients, or a per-pair block-count matrix. If the input has dense tight-triangle clusters, ABCD scatters those edges uniformly across each cluster's admissible pairs instead.

profiling · cluster sizes

One integer per cluster, sum to \(n\).

The second file is cluster_sizes.csv, an integer size per cluster, sorted size desc. The paper requires \(\sum_j s_j = n\), so every input node lands in exactly one cluster. Our wrapper satisfies this via outlier_mode=singleton: every unclustered input node becomes a 1-node pseudo-cluster (ID __outlier_<id>__), so the size list sums to \(n\). Real clusters sort to the top; singletons tail.

The sampler uses this list for two things. First, vertex-to-cluster assignment respects a size cap: a vertex of degree \(w_u\) can land in cluster \(j\) only if its admissibility bound \(x_u\) (next section) satisfies \(x_u \le s_j - 1\). Second, each cluster graph is generated on exactly the members assigned to it, so the output partition has sizes matching the input verbatim.

profiling · the mixing scalar

One number: \(\xi\).

The third file is mixing_parameter.txt, a single float. Let \(E_{\text{out}}\) be the number of edges crossing cluster boundaries under the profile's clustering (singletons count, so outlier-incident edges are "inter" when the other endpoint is a different cluster). Then

\[ \xi \;=\; \frac{E_{\text{out}}}{|E|}. \]

The paper reads \(\xi\) as the expected fraction of each vertex's weight that the model routes to the background graph: \(\xi w_u\) background stubs, \((1 - \xi) w_u\) cluster-graph stubs. The realised inter-cluster fraction on output hits \(\xi\) only in expectation; on small graphs it drifts by a few percent seed-to-seed.

ABCD's \(\xi\) vs LFR's \(\mu\): not the same number

Both measure "fraction of edges crossing clusters" on the same input graph, but via different reductions. ABCD's \(\xi\) is a stub-weighted ratio over all edges, \(E_{\text{out}} / |E|\). LFR's \(\mu\) is the mean of per-node ratios, \(\text{mean}_u(w^{\text{out}}_u / w_u)\). On skewed-degree inputs the two diverge: on dnc ABCD's \(\xi\) is 0.72 while LFR's \(\mu\) is 0.69. Do not swap them across models.

generation · assigning vertices to clusters

Big nodes to big clusters; small nodes fill the rest.

Before any edges are drawn, the sampler assigns each vertex to exactly one cluster. The assignment is chosen uniformly at random from the admissible permutations. Admissibility is defined by a per-vertex bound the paper calls \(x_u\), the expected number of neighbours of \(u\) that will end up in \(u\)'s own cluster:

\[ x_u \;=\; \bigl\lceil (1 - \xi \phi) \, w_u \bigr\rceil, \qquad \phi \;=\; 1 - \sum_{j=1}^{k} \left(\frac{s_j}{n}\right)^{\!2}. \]

A permutation mapping vertex \(u\) to cluster \(j\) is admissible iff \(x_u \le s_j - 1\) (a vertex cannot have more intra-cluster neighbours than the cluster has other members). The sampler walks vertices in descending \(w_u\), tracks remaining slots per cluster, and samples the cluster for each vertex with probability proportional to that cluster's remaining capacity, restricted to clusters whose size still admits the vertex.

On inputs with no degree-0 nodes (like dnc, where every node has at least one edge), positive-degree vertices fail the admissibility for any singleton cluster (size \(s_j = 1\) requires \(x_u \le 0\), but \(\lceil (1-\xi\phi) w_u \rceil \ge 1\) for any \(w_u \ge 1\)). The sampler falls back: when every real cluster is full and a small-degree vertex is still unplaced, it takes the leftover singleton, issues a bad_weights warning, and moves on. Final \(\xi\) is biased by how many singletons had to absorb non-zero-degree vertices.

outliers in ABCD are a wrapper idea, not a model parameter

The paper has no notion of "outlier"; it takes cluster_sizes.csv with \(\sum_j s_j = n\) and asks no further questions. Our wrapper's outlier_mode=singleton makes every unclustered input node a 1-node pseudo-cluster so the sum identity holds, and the post-processing step drop_singleton_clusters strips them from com.csv at the end. ABCD+o is the extended model that promotes outliers into a proper model-level parameter \(s_0\).

generation · the weight split

Drag \(\xi\). Each node's weight repartitions.

With the cluster assignment fixed, the sampler splits each vertex's weight:

\[ y_u \;=\; (1 - \xi) \, w_u, \qquad z_u \;=\; \xi \, w_u. \]

\(y_u\) funds the cluster graph \(G_{c(u)}\); \(z_u\) funds the background graph \(G_0\). For the exact-degree variant (our default), the cluster's non-leader members are rounded stochastically so \(\mathbb{E}[\hat y_u] = y_u\): \(\hat y_u = \lfloor y_u \rfloor + \mathbb{1}\{U_u < y_u - \lfloor y_u \rfloor\}\) with \(U_u \sim \text{Uniform}(0, 1)\). The leader (largest-weight member) takes the deterministic floor \(\lfloor y_\ell \rfloor\) and adds 0 or 1 by parity: the bump fires when the sum of non-leader \(\hat y_u\) is odd and the floor is even, or vice versa, so the cluster's total internal stub count ends up even. \(\hat z_u = w_u - \hat y_u\).

generation · cluster pairing

Pair \(\hat y_u\) stubs inside each cluster.

Each cluster graph \(G_j\) is a configuration model on its members' \(\hat y_u\) stubs. Each node \(u\) with \(c(u) = j\) contributes \(\hat y_u\) stubs as spokes around the node; they shuffle within the cluster and pair adjacent. generation · cluster rewire

Cut the collisions, swap into valid edges.

Cluster-graph collisions (self-loops and parallels) move to a recycle list. Each is paired with a random other cluster edge \((p_2)\); the four endpoints get re-stitched as \((p_1[0], p_2[0]), (p_1[1], p_2[1])\) (or the swapped variant) and accepted if both new edges are simple. The rewire loop runs until the cluster graph is collision-free or runs out of moves.

intra-cluster edges can come from either graph

The cluster graph \(G_j\) sees only its members' \(\hat y_u\) stubs, so every edge of \(G_j\) is intra-cluster by construction. But \(G_0\) pairs \(\hat z_u\) stubs across the whole vertex set, and sometimes pairs two members of the same cluster. Those extra intra-cluster edges count toward the cluster's internal density; they are why the paper shows, for the global variant, a small upward drift of intra-cluster density with cluster size.

caveat: \(\xi\) is the only structural dial

ABCD does not target an edge-count matrix. If the input has a block pair \((r, s)\) with 200 crossing edges and \((r, t)\) with 20, the sampler only sees each node's \(\hat z_u\) and pools them globally; \((r, s)\) and \((r, t)\) end up with the count dictated by random pairing weighted by endpoint weights, not the empirical figures. SBM and the EC-SBM family honour per-pair block counts; ABCD does not.

generation · degree preservation

Output degrees match input almost exactly.

The rewire loop is the part of ABCD most often misread as "best-effort". On our 20-node synthetic, across 10 seeds of the real Julia sampler, the output's sorted-degree-desc multiset exactly matches the input's in 9 of 10 runs; the remaining run loses a single edge (a handful of stubs that the rewire could not swap cleanly).

caveat 1: the cc gap is the price of "only \(\xi\)"

dnc's input global cc is 0.548. ABCD lands at 0.307. The gap is what "configuration model inside each cluster" produces on an input with structured triangles: the sampler has no way to preserve them. EC-SBM v2's \(K_{k+1}\) core and nPSO's hyperbolic embedding trade some of ABCD's tractability for a handle on clustering.

caveat 2: node identity is not preserved

The sampler sorts the profile's degrees by descending \(w_u\) and re-assigns them to clusters uniformly over admissible permutations. "Node 5" in the output is not node 5 in the input; the two are unrelated. What is preserved across every seed: the degree multiset (up to rewire drift) and the cluster size multiset (exact).
