network-generation · abcd

ABCD

Artificial Benchmark for Community Detection. Passes the input's degree sequence and cluster sizes through verbatim; one scalar \(\xi\) sets the fraction of stubs that cross cluster boundaries. A configuration model inside each cluster, a configuration model globally, rewire the collisions.

You have a real network and its clusters. You want a synthetic twin that keeps both exactly as given but draws its edges fresh. ABCD reads every node's degree out of the input, reads every cluster's size out of the input, asks one question ("what fraction of edges cross cluster boundaries?"), and the rest is configuration model.

Unlike LFR, ABCD does not fit a power law to your degrees and resample. The sequence you hand in is the sequence each node carries into the sampler. Rewire of self-loops and parallel edges can nudge individual degrees by a step or two, but the multiset is preserved in expectation.

The catch: \(\xi\) is the only structural dial. ABCD does not know about the block-matrix pairs of SBM, nor triangles, nor clustering coefficients. If the input's intra-cluster edges concentrate on a few tight triangles, ABCD spreads them instead. Pick by what you need preserved, not by runtime.

profiling · degree sequence

Every node's degree, read once and passed through.

Profile writes three things at stage one. The first is degree.csv, the per-node integer degree of the input, sorted desc. The Julia sampler reads this unchanged and uses it as the node-degree distribution. Rewire at the last step of generation can shift individual degrees by a unit when a collision fails to resolve, but the multiset is preserved.

profiling · cluster sizes

One integer per cluster, verbatim; outliers become singletons.

The second file is cluster_sizes.csv, the integer size per input cluster, sorted size desc. Under the default outlier_mode=singleton, each unclustered input node becomes a 1-node pseudo-cluster (ID __outlier_<id>__) and shows up in the list with size 1. The sampler sees the singletons and the real clusters as indistinguishable, a flat list of target sizes summing to \(N\). Real clusters sort to the top, singletons to the bottom.

The main constraint the Julia sampler enforces on the size list is the admissibility cap: when attaching degree-\(d\) nodes to clusters, node \(i\) can join cluster \(C\) only if \(d_i \le s_C - 1\) (you cannot owe more edges to your cluster than your cluster has other members). Large-degree nodes therefore fall into large clusters; a degree-8 hub in our synthetic cannot land in a size-1 singleton.

profiling · the mixing scalar

One number: \(\xi\).

The third file is mixing_parameter.txt, a single float. Let \(E_{\text{out}}\) be the number of edges crossing cluster boundaries and \(E\) the total edge count. Then

\[ \xi \;=\; \frac{E_{\text{out}}}{E} \;=\; \frac{\sum_u d^{\text{out}}_u}{\sum_u d_u}, \]

where \(d^{\text{out}}_u\) counts \(u\)'s edges that leave its home cluster. The right-hand form makes the stub-weighting explicit: each edge contributes two stubs, each stub contributes once. A 368-degree hub with 200 inter-cluster edges contributes 400 stubs to the numerator; a 3-degree node with 1 inter-cluster edge contributes 2. Hubs dominate.

Under outlier_mode=singleton, every edge touching an outlier is inter by definition (each outlier is its own 1-node cluster). That lifts \(\xi\) well above the "real" inter-cluster fraction on graphs with many outliers. On dnc it lifts \(\xi\) from 0.31 (if we pretended outliers were invisible) to 0.72. The case study below walks through the knock-on effect.

ABCD's \(\xi\) vs LFR's \(\mu\): not the same number

Both scalars measure "fraction of edges crossing clusters" on the same input graph, but via different reductions. ABCD's \(\xi\) is stub-weighted, \(\xi = (\sum_u d^{\text{out}}_u) / (\sum_u d_u)\). LFR's \(\mu\) is node-mean, \(\mu = \text{mean}_u(d^{\text{out}}_u / d_u)\). On skewed-degree inputs the two diverge: on dnc ABCD's \(\xi\) is 0.72 while LFR's \(\mu\) is 0.69. Do not swap them across models.

generation · the \(\xi\) split

Drag \(\xi\). Each node's stubs repartition.

At generation time the Julia sampler takes the degrees, takes the cluster-size list, takes \(\xi\), and first decides, per node, how the degree splits:

\[ d^{\text{ext}}_i \;=\; \mathrm{round}(\xi \cdot d_i), \qquad d^{\text{int}}_i \;=\; d_i - d^{\text{ext}}_i. \]

Internal stubs stay inside the home cluster; external stubs go to the global pool. Per-node rounding means the global external fraction matches \(\xi\) only in expectation. The fluctuation shrinks as \(N\) grows, so on large inputs the realised \(\xi\) hugs the target tightly; on small inputs (like this 20-node synthetic) the rounding integer-steps the totals visibly.

per-node rounding bias

A node with degree 2 and \(\xi = 0.333\) rounds to \(d^{\text{ext}} = 1\) (realised 0.5). A degree-5 node rounds to \(d^{\text{ext}} = 2\) (realised 0.4). Low-degree nodes systematically overshoot \(\xi\), high-degree nodes undershoot. On a heavy-tail degree sequence the global drift hides in the third decimal; on a narrow sequence it is visible.

generation · configuration model

Shuffle the stubs. Pair them. Rewire collisions.

Two passes, both pure configuration model. Internal: for each cluster \(C\), flatten the \(d^{\text{int}}_i\) stubs of its members into one list, shuffle, pair adjacent. External: flatten every node's \(d^{\text{ext}}_i\) stubs into one global list, shuffle, pair adjacent. Every stub ends up paired. Then a rewire pass walks the edge list and swaps endpoints until no self-loop or parallel edge remains.

node identity is not preserved

ABCD reads its inputs as anonymous TSVs. It re-assigns the degree sequence to clusters under the \(d_i \le s_{C(i)} - 1\) cap and writes the output with its own integer indexing. "Node 5" in the output is not node 5 in your input. The multiset of degrees and the multiset of cluster sizes are preserved, but the identity mapping is not. If you need stable IDs, an SBM variant passes the input clustering through and keeps the block assignment fixed.

caveat: \(\xi\) is the only structural dial

ABCD does not target an edge-count matrix. If the input has a block pair \((r, s)\) with 200 crossing edges and \((r, t)\) with 20, the sampler only sees each node's external-stub count and pools them globally; \((r, s)\) and \((r, t)\) end up with the count dictated by uniform pairing, not the empirical figures. ABCD+o adds an outlier-block constraint on top of \(\xi\) but inherits the same single-dial limit. SBM and the EC-SBM family honour per-pair block counts; ABCD does not.

caveat 1: cc gap is the price of "only \(\xi\)"

dnc's input global cc is 0.548. ABCD lands at 0.307. The cc gap is not a bug, it is what "configuration model inside each cluster" produces on an input with structured triangles: the sampler has no way to preserve them. EC-SBM v2's \(K_{k+1}\) core and nPSO's hyperbolic embedding each trade some of ABCD's tractability for a handle on clustering.

caveat 2: \(\xi\) conflates outliers with cluster boundaries

Under the default outlier_mode=singleton every outlier-incident edge becomes "inter" even when the outlier connects to the same real cluster repeatedly. On dnc this lifts \(\xi\) from roughly 0.31 (the real inter-cluster fraction) to 0.72 (the inter-cluster fraction that counts each outlier as its own boundary). The sampler dutifully reproduces 0.72, which means the output's 355 outlier nodes spread their stubs across the real clusters more widely than the input's outliers do. Switching to outlier_mode=combined would merge all outliers into one pseudo-block and recompute \(\xi\) against that; ABCD does not ship that path, but its sibling ABCD+o offers a related alternative.
